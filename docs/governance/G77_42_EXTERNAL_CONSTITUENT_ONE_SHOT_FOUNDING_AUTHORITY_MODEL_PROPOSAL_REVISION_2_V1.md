## B05 — Canonical Encoding and Complete Schema Registry

### CJ1 canonical encoding

All Revision 2 identities use `CJ1`:

- UTF-8 without BOM and Unicode NFC strings;
- JSON objects only with unique keys sorted by unsigned UTF-8 key bytes;
- arrays retain declared order;
- strings use JSON escaping for quote, reverse solidus, and U+0000–U+001F,
  with lowercase four-hex Unicode escapes only when escaping is required;
- `/` and all other valid Unicode scalar values are unescaped;
- integers are base-10 with no leading zero and no `-0`; floats are forbidden;
- booleans are `true`/`false`; null is `null`;
- no insignificant whitespace, duplicate key, NaN, infinity, wildcard,
  omitted declared field, map-order input, or alternate representation; and
- timestamps are uppercase `YYYY-MM-DDTHH:MM:SS.ffffffZ` strings.

Every artifact has this common envelope, in addition to its exact semantic
schema:

~~~text
artifact_type
artifact_version
artifact_identity
artifact_digest
contract_version
idempotency_identity
producing_owner
metadata = {}
~~~

No envelope field is null. `metadata` is present and exactly empty. Unknown
fields fail closed. For artifact A, let `S_A` be the CJ1 object containing the
common non-identity fields `artifact_type`, `artifact_version`,
`contract_version`, `producing_owner` plus every semantic field in its exact
schema, excluding `artifact_identity`, `artifact_digest`,
`idempotency_identity`, and `metadata`.

~~~text
A.idempotency_identity = <A-idem-prefix>:SHA256(CJ1(S_A))

P_A = S_A plus A.idempotency_identity

A.artifact_identity = <A-prefix>:SHA256(CJ1(P_A))
A.artifact_digest = sha256:SHA256(CJ1(P_A))
~~~

Same `S_A` returns byte-identical P_A and the identical artifact. Same
idempotency or artifact identity with different CJ1 bytes fails closed and
permanently invalidates the exact target slot when the Universe is admissible.

## B06 — Authoritative Invalidation Terminalization

The authoritative invalidation domain is the exact external target-disposition
domain committed by the independently prior Universe. It is not a new current
Constitutional root, internal pointer, owner, registry, or lifecycle.

Its complete state machine is:

~~~text
UNUSED
  -> DECISION_BOUND_ADOPT
  -> CONSUMING
  -> CONSUMED_DORMANT

UNUSED -> REFUSED_DORMANT
UNUSED or DECISION_BOUND_ADOPT -> INVALIDATED_DORMANT
CONSUMING -> INVALIDATED_DORMANT only from exact losing root-CAS evidence
~~~

`REFUSED_DORMANT`, `INVALIDATED_DORMANT`, and `CONSUMED_DORMANT` have no
outgoing edge. `DECISION_BOUND_ADOPT` binds the final Human choice but not
effect eligibility. `CONSUMING` is the sole external fence from which the
internal root CAS is permitted.

2. `BEGIN_EXACT_ROOT_CONSUMPTION`, permitted only after finalized ProofSet,

The consumption candidate derives one `consumption_fence` from those exact

~~~text

source status = REVOKED
-> external target-slot CAS INVALIDATED_DORMANT
~~~
