## Authority Non-Creation Proof

The contract is a recognizer of complete facts, never their source:

~~~text
contract bytes exist
AND external Premise absent
-> E2 false
-> INELIGIBLE

internal validators accept canonical bytes
AND independently prior provenance/authority predicate false
-> E2 false
-> INELIGIBLE

AND external normative-authority premise absent or circular
-> E2 false
-> INELIGIBLE

AND independently prior Premise/Instrument absent
-> E2/E3/E4 false
-> INELIGIBLE
~~~

Therefore:

~~~text
contract existence != external authority existence
internal validation != constituent authority creation
valid signature != normative authority
Human approval alone != independently prior constituent authority
~~~

The external Premise's anti-self-authorization proof and complete predecessor
manifest must exclude derivation from the current/target/successor

external authority precedes the contract normatively. It may issue its exact
TargetV4-bound Instrument only after TargetV4 bytes are finalized; that later
target binding does not make the contract a predecessor of the authority's
existence.

No contract owner is added. Root custody produces TargetV4 deterministically
and performs later assigned effects; it does not recognize normative authority
by discretion.

## One-Shot Lifecycle

No new lifecycle State is introduced. The proposed contract exposes two
derived validation results over the existing Candidate H state machine:

| Requested label | Exact status | Persistence/authority meaning |
|---|---|---|
| `INELIGIBLE` | derived result | one or more E1-E11 predicates false; no State, BEGIN, or root authority |
| `ELIGIBLE` | derived result | E1-E11 true while exact external slot is `DECISION_BOUND_ADOPT`; permits BEGIN evaluation only |

| `CONSUMED_DORMANT` | existing terminal external slot/Dormancy result | one successful founding effect; no outgoing edge |
| `REFUSED_DORMANT` | existing terminal external slot/Dormancy result | exact final Human REFUSE; no effect and no outgoing edge |

Lifecycle reduction:

~~~text
missing/invalid facts -> INELIGIBLE
complete ADOPT facts -> ELIGIBLE
ELIGIBLE + winning exact BEGIN -> CONSUMING
CONSUMING + successful root/read-back -> CONSUMED_DORMANT
final Human REFUSE -> REFUSED_DORMANT

-> INVALIDATED_DORMANT

CONSUMING + internal reconstruction failure -> ABANDONED token K
-> only same external event may retry with new current root/ordinal
-> no new authority, target, Human decision, or event
~~~

No terminal external State has an outgoing edge. `ABANDONED` is terminal for
its internal token/candidate, not a terminal external disposition and not a
reset. A same-event retry remains bound to the identical TargetV4, Premise,
Instrument, Human Finality, external CONSUMING slot, Snapshot/Fence/BEGIN
