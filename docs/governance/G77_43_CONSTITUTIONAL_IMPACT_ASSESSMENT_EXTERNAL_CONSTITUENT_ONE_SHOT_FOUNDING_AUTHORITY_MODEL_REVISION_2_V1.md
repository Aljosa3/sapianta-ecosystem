## Authoritative Invalidation and Concurrency Attack

G77-42 fixes G77-41's local-projection defect in principle: only a target-slot
CAS/read-back in the independently prior external domain may claim
`INVALIDATED_DORMANT`. Terminal refused, invalidated, and consumed slots have
no outgoing edge. Reversal to a later `ACTIVE` report cannot reopen a terminal
target slot.

The exact unresolved inter-domain execution is:

~~~text
T1: consumption path reads Universe/source/Instrument status ACTIVE
T2: external source status authoritatively becomes REVOKED
T3: target-slot CAS uses T1 snapshot and wins
    DECISION_BOUND_ADOPT -> CONSUMING
T4: proposal classifies T2 as later than CONSUMING
    even though T2 was authoritative before T3
~~~

The target-slot CAS compares the target disposition predecessor. It does not
compare an exact current pointer/version/generation from every status domain,
and no common atomic read/CAS domain is defined. Binding the earlier status
snapshot inside `consumption_fence` proves which bytes were read; it does not
prove they were current at T3. Consequently invalidation and BEGIN_CONSUMPTION
are not one total order when the invalidating fact originates outside the
target-slot domain.

| Crash/concurrency boundary | Independent result |
|---|---|
| crash before target CAS | no consuming or terminal authority; fail closed |
| crash during target CAS | target slot exposes predecessor or successor |
| crash after consuming CAS before root CAS | exact consuming slot is durable |
| root CAS | one existing-domain successor wins |
| crash after root CAS | current root is predecessor or exact successor |
| losing root CAS | external invalidation is structurally authorized |
| revocation after consuming linearization | cannot reinterpret already-authorized one-shot content |
| revocation before consuming but after status snapshot | stale consuming CAS can win; `NEW_BLOCKER` |
| later ACTIVE after terminal invalidation | terminal slot remains unchanged |

B06 remains unresolved even though external terminal-state authority and
post-terminal irreversibility are otherwise correctly modeled.
