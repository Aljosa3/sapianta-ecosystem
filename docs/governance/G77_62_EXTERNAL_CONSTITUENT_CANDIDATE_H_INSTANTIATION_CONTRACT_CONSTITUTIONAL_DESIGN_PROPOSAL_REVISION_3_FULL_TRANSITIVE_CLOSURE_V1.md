## Canonical Contract Framework

Every new or completely replaced Revision 3 artifact below uses CJ1: UTF-8
without BOM, NFC strings, unique object keys sorted by unsigned UTF-8 key
bytes, canonical JSON escaping, base-10 integers without leading zero or
negative zero, no float/NaN/infinity, exact booleans/null, and no whitespace or
unknown keys. Array order is the declared protocol order.

~~~text
artifact_type

<artifact-specific digest field>

~~~

Let `S_A` be the CJ1 object containing exact type/version/contract/owner and
every semantic field in A's complete payload below, excluding its own identity,
digest, idempotency, and metadata. Let `P_A` be `S_A` plus the derived
idempotency identity.

~~~text
A.idempotency_identity = <A-idem-prefix>:SHA256(CJ1(S_A))
A.identity = <A-prefix>:SHA256(CJ1(P_A))
A.digest = sha256:SHA256(CJ1(P_A))
~~~

Same semantic bytes return the identical artifact. Same idempotency or
identity with different bytes, wrong type/version/owner/prefix, half-pair,
unknown field, invalid null, or non-CJ1 content fails closed.
