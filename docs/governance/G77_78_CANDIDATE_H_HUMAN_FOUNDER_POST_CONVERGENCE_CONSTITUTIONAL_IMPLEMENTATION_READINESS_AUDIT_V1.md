The current design reduces to one forward chain:

~~~text
G76 identity/DAG rules
-> independently accepted External Premise and persisted source evidence
-> CapacityV2 authenticated issuance/custody
-> HFD-04 canonical act candidates and exact review projection
-> one Human disposition and exact P_auth_v2
-> G77-77 exact retry equality tuple
-> one G77-73 logical operation/claim/signer acceptance

-> FoundingTransitionV3 -> Fence/BEGIN
-> allocation/Coordinator -> LogicalPointer/Projection/Manifest/Census
-> CAP -> Guard -> MetaRepair
-> terminal Commitment/ConsumeIntent/CoordinatorV4/RootSnapshotV4
-> root CAS/read-back -> terminal Receipt/Dormancy/exhaustion
-> owner-local read-only Replay -> passive CRO

after successful founding:
ordinary constitutional change only through G70 Gap -> Proposal -> Assessment
-> Human Ratification -> Certification -> Publication -> Activation
~~~

The architecture has one Human entry, one founding operation, one result
winner, one root path, and no persistent Founder authority. HIC/CHE transports
the Human act but cannot select its meaning. Certification validates
predicates but cannot originate authority. Replay reconstructs and CRO
observes; neither can write or repair.
