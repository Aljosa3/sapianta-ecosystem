Independent implementation-semantic blocker:
`G77_81_B02_V1_IMPORT_AND_QUERY_AVAILABILITY_COUPLED_TO_V2_CANDIDATE_RECONSTRUCTOR`.

G77-81 closes the value-level catalog-token and dispatch gap, but it does not
close module-load version isolation. The current catalog representation stores
an actual reconstructor callable in every `EvidenceAdapter`; `_adapter`
immediately derives `reconstructor_name` from that callable. G77-81 requires
the exact Candidate callable
`aigol.runtime.candidate_h_founder.replay.reconstruct_candidate_h_founder_replay_v1`
as V2 row 15 and requires both catalogs/maps in the same modified
`catalog.py`.

Therefore the straightforward implementation necessarily imports the new
Candidate package while `catalog.py` loads. Existing public package import is:

~~~text
constitutional_runtime_observatory.__init__
-> core
-> catalog
-> every module-level reconstructor, including the V2 Candidate reconstructor
~~~

This happens before `build_constitutional_human_intent_journey_v1` receives or
selects a catalog token. If the Candidate package, its initializer or any
transitive Replay dependency is absent or import-failing, omitted/default V1
and explicit V1 become unavailable before V1 can be selected. The certified
fourteen-row V1 projection bytes may remain equal once import succeeds, but
historical V1 query availability is no longer isolated from V2.

G77-81 declares that default/import behavior is preserved and that no hidden
transitive version cascade exists, yet it specifies no deterministic isolation
mechanism. A split V2 module, lazy callable resolver, deferred catalog factory,
callable-reference type, or altered adapter factory would each create a
different file/data/API/test contract. Selecting among them here would repair
G77-81 and is prohibited.

The eleven-test inventory also misses the corresponding hostile proof: V1
package import and V1 catalog/query use must succeed when the Candidate V2
module is unavailable or deliberately raises on import. G77-81 test 6 proves
only that V1 rejects the Candidate adapter before invoking its reconstructor;
it does not prove that the reconstructor module was never imported.

Consequences:

- version selection does not precede module/reconstructor import;
- `__init__.py` and `core.py` modifications are not sufficient to establish

- exact 11 CREATE / 4 MODIFY / 13 REUSE scope is not authorizable until the
  isolation owner/file contract is fixed;
