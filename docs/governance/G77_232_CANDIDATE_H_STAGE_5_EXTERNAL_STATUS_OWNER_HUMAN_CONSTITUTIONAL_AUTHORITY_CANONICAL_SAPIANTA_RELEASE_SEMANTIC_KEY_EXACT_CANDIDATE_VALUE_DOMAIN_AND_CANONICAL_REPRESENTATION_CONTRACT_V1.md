nibble first, to exactly two characters from `0123456789abcdef` at textual
positions 0 through 63. Let `dec(S)` perform the inverse only when `S` matches
`^[0-9a-f]{64}$`.

```text

  dec(enc(V)) = V

FOR EVERY CANONICAL S:
  LENGTH(dec(S)) = 32 OCTETS
  enc(dec(S)) = S

FOR EVERY NONCANONICAL S:
  dec(S) = REJECT
```
